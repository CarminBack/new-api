# Yeepay 渠道 282 后台同步

入口：模型定价 → 上游价格同步 → 渠道 282 利润价格同步。

先预览，再应用。此入口独立于 AistarsLab，使用渠道启用的密钥，通过既有代理设置请求固定的 Yeepay HTTPS 目录；密钥只留在服务端，请求禁止重定向。

## 管理员操作

- 核对每美元积分、成本加价百分比、向上取整小数位数。首次显示 10、35%、2 位，属于可编辑预览值；不代表自动执行历史价格授权。成功后保存汇率、加价率及精度。
- 默认保留现有模型选择，仅补入当前插件从未适配的新型号；不会重新加入管理员手工排除的旧型号。勾选“加入全部可用模型”才补齐目录现有型号。已下架型号、旧任务支持和映射保留，并列入警告。
- 默认保留已有售价；新选中且没有独立价格的型号会列出拟新增价格。勾选“更新已有 Yeepay 售价”才更新已有型号。
- 预览显示新增型号、售价、表达式、能力和插件版本。修改任意输入或上游/本地配置漂移后，必须重新预览。

价格继续使用模型级 `billing_setting.billing_mode` / `billing_setting.billing_expr` / `ModelPrice`，公式为上游积分价 ÷ 每美元积分 × 成本加价倍率，再按选择精度向上取整。支持每条和输出秒，以及明确声明的带参考视频输出秒价；明确声明 `reference_video_billing=separate_seconds` 的参考秒价格复用现有插件参考秒用量与公式；参考视频显式禁用时保持禁用。token 费用不推断。更新时只清除该模型旧的 Yeepay 专属覆盖，保留其他提供商覆盖。

模型级价格为多个渠道共享。若拟写价格的模型名也被其他供应商渠道直接使用，或被其映射链引用，预览及应用事务均拒绝，要求先处理命名冲突。自定义映射的模型不自动重定价。

## 后端契约

`POST /api/ratio_sync/yeepay/sync` 使用既有 RootAuth。

请求字段：`dry_run`、`channel_id:282`、`credit_rate`、`markup_rate`（成本倍率，如 1.35）、`decimal_places`（0–6）、`all_models`、`update_prices`。应用还须提供上一次预览的 `preview_token`。

目录只提供结构化事实；未知的 99999 素材最大值不公开为上限，显式 false/0 保留，auto/adaptive 比例不转成普通比例，edit/extend 不声明为可用。不认识的计费/能力契约、模板变化或无效候选直接拒绝，交由人工适配。

从正在使用的持久化插件生成候选，保留其鉴权、查询和下载代码，以及旧型号。候选经过宿主编译、路由冲突检查、计费表达式验证；相同目录产生相同版本。插件、渠道、价格、设置及最近一次回退快照在同一事务提交。提交后沿用既有插件加载器发布，再检查运行时版本。若发布失败，接口明确说明配置已保存，须检查运行时后再操作。

## 回退与验证

每次应用将此前的渠道模型/映射、插件版本/哈希和被修改模型的原配置存入 `YeepaySyncBackup`（不含渠道密钥）；旧插件源码留在既有插件版本表。该快照保留最近一次应用前状态，下一次应用会替换。维护人员可通过既有配置接口和乐观版本恢复相应模型配置、渠道选择，并激活旧插件版本；不恢复业务数据库。回退前仍须按生产变更规则确认精确范围。

SQLite、MySQL 8、PostgreSQL 16 已实测事务提交、写入失败回滚、预览失效、管理员模型选择保护、其他提供商覆盖保留和跨供应商同名冲突。真实捕获的 36 模型离线宿主编译、提交描述与 usage 提取通过。前端测试覆盖预览参数、应用令牌、默认保护、输入变化及无效汇率。

本功能上线只增加后台入口；模型、插件和售价由管理员在入口预览后应用。离线验证不代表付费生成、成品完整下载或真实播放已验收。

2026-11-13 首次发布的只读预览因上游目录新增参考秒计费被原严格校验拒绝，已回退原镜像，业务配置未变。修正后以当日 36 型号及生产配置快照离线验证默认保价/显式更新两种预览，另验证参考秒缺失拒绝及 10 输出秒＋6 参考秒的精确费用。
